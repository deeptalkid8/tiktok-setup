WhatsApp Content Publisher

WhatsApp Content Publisher is an automation project that helps authorized users publish their own videos and captions to supported social media platforms.

How It Works

Users submit a video and caption through WhatsApp. The n8n workflow validates the content and processes the publication using the user's authorized account.

Data and Privacy

The application processes submitted videos, captions, and the account authorization data required for publishing. Credentials are intended to be stored securely and used only for the authorized workflow.
